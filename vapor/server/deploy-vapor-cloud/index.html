部署到 Vapor Cloud

一条命令把 Vapor 3 项目推上云。本文展示 vapor cloud deploy 的完整部署流程，以及如何取消部署并清理资源。

部署

取消部署并删除

首先需要把部署的机器数变为 0：

$  vapor cloud deploy --replicas=0

然后在 Vapor 云上自己的帐号中，从内到外一级一级删除。
