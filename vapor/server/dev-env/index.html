开发环境准备

动手写第一行 Vapor 代码前，先把开发环境搭好。本文带你分别在 macOS 和 Ubuntu 上安装 Swift 与 Vapor 工具箱，并配置顺手的编辑器。

支持的平台

目前，Vapor 的开发环境主要是在 macOS 和 Ubuntu 两个平台部署。macOS 平台上可以借助 Xcode 这个 IDE 进行开发。在 macOS 上你要先安装好 Xcode，Xcode 内置有 Swift 开发环境，Vapor 要求 Swift 版本在 5.2 及以上。使用 shell 命令查看 Swift 版本：

swift --version

下面是 macOS 和 Ubuntu 两个系统平台上部署 Vapor 开发环境的具体步骤。

macOS 平台

  1. 先从 App Store 安装开发工具 Xcode（Swift 开发环境）。
  2. 再到 Homebrew 官网，安装 Homebrew 包管理器： 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. 使用 Homebrew 包管理器安装 Vapor 开发工具： 
    brew install vapor

Ubuntu 平台

  1. 浏览 Swift 官网，按照官方指导，下载 Swift 工具链并安装开发环境，安装完成后查看 swift 版本号：swift --version。
  2. 从源码安装 Vapor： 
    git clone https://github.com/vapor/toolbox.git
cd toolbox
git checkout <desired version>
make install

检查 Vapor 是否安装成功

vapor --help

执行完上面的步骤，Vapor 的开发环境就布置完成了。

如果你的开发平台是 macOS，建议使用 Xcode 作为开发工具。目前在 Ubuntu 上还没有对 Swift 支持比较好的 IDE，可以使用 Visual Studio Code 安装 Swift 插件的方式进行开发，命令行下也可以使用 Vim 编辑器进行 Swift 相关开发。

用 Xcode 打开工程（macOS）

只需要在 Vapor 创建的项目根目录下运行命令，即可打开 Xcode 工程进行开发：

cd HelloVapor
vapor xcode   # 也可以使用 open Package.swift 的方式让Xcode打开SPM项目工程

用 Visual Studio Code 开发（通用）

  1. 本地需要先安装好 Swift 环境。
  2. 安装 Visual Studio Code。
  3. 安装 Visual Studio Code 插件：sswg.swift-lang，插件的相关文档可以参考：README。
  4. 使用 Visual Studio Code 打开 Vapor 工程根目录。
  5. 运行、打断点、调试可以直接按常规操作进行。
