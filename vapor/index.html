Vapor 系列教程

56 篇文章

Vapor 是一个用纯 Swift 编写的服务端框架，底层基于苹果的非阻塞网络库 SwiftNIO。你可以用同一门语言同时包揽 iOS 客户端与后端，复用数据模型，不必在语言之间来回切换。下面有两条路线：先「快速上手」建立整体印象，再跟着「大型教程」逐章吃透。

版本说明：「快速上手」示例对应 Vapor 4（当前主版本）；「大型教程」内容整理自 vapor.jokerhub.cn 的《Vapor 大型教程》，原文使用 Vapor 3，代码已忠实保留（如 router.post、Future<>、flatMap(to:)）。两者核心思想一致，主要是 API 命名差别，按需取用即可。
