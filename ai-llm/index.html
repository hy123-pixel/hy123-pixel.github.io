从 0 开始理解大语言模型

不讲玄学，从 Token、Transformer 到推理，一次建立对 LLM 的完整认知。

基础概念适合：AI 初学者 / 开发者

01 · 模型到底在做什么

大语言模型（LLM）最基本的工作，是根据已经看到的上下文，预测下一个 Token。Token 可以是一个字、一个词，也可以是词的一部分。模型不会先写好完整答案再交给你，而是一次预测一个 Token，逐步构造出句子。

这解释了两个常见现象：同一个问题多问几次，答案可能不同；当上下文里没有可靠证据时，模型也可能生成“听起来正确”的内容。它擅长语言模式，不等于天然拥有事实核验能力。

GENERATE
今天→的→天气→很?
每一步都在计算下一个 Token 的概率分布

02 · Transformer 为什么重要

Transformer 的核心是注意力机制。处理当前 Token 时，模型会动态关注上下文中更相关的部分，因此能把“指代关系”“前后条件”和“远距离语义”连接起来。它还能并行处理训练数据，成为今天大模型的基础架构。

一个实用的类比：注意力机制像一支荧光笔。读到每个词时，模型会重新决定应该把重点标在哪些上下文上。

03 · 训练、对齐与推理

预训练让模型从海量文本中学习语言规律；指令微调让它更容易遵循人类要求；偏好对齐让回答更安全、更符合使用习惯。到了推理阶段，模型只根据输入上下文和采样策略生成结果。

所以“参数量更大”只是能力上限的一个因素。上下文是否完整、任务是否定义清楚、是否提供了工具和验证步骤，往往更直接地决定应用效果。

04 · 开发者应该关注什么

  1. 先定义任务：是生成、分类、抽取，还是需要事实核验？
  2. 再选择上下文：把必要信息放进 Prompt，避免无关内容淹没重点。
  3. 最后设计验证：结构化输出、规则校验、引用来源，都是应用的一部分。
输入：用户问题 + 可信上下文
模型：理解任务并生成候选答案
程序：校验格式、来源和权限
输出：答案 / 不确定性 / 可追溯依据

理解原理不是为了背概念，而是为了知道问题应该在模型、数据还是工作流里解决。
