从 0 开始理解大语言模型

不讲玄学，从 Token、Transformer 到推理，一次建立对 LLM 的完整认知。

01 · 模型到底在做什么

大语言模型本质上是在大量文本上学习“下一个 Token 最可能是什么”。Token 可以是一个字、一个词，也可以是词的一部分。模型在每一步预测的基础上，逐步构造出连贯的内容。

02 · Transformer 为什么重要

Transformer 的核心是注意力机制：模型可以在处理当前 Token 时，动态关注上下文中更重要的部分。相比早期按顺序处理文本的网络，它更容易并行训练，也能建立远距离的语义联系。

一个实用的类比：注意力机制像一支荧光笔。读到每个词时，模型会重新决定应该把重点标在哪些上下文上。

03 · 训练与推理

预训练让模型学会语言规律和世界知识；指令微调让它更像一个听得懂要求的助手；推理阶段则是根据输入和采样策略生成答案。参数量大不等于每个问题都答得好，输入质量、上下文和验证机制同样重要。

04 · 开发者应该关注什么

  • 先明确任务边界，再选择模型和上下文长度。
  • 用结构化输出约束结果，而不是只说“请认真回答”。
  • 把事实性任务交给检索和工具，把表达性任务交给模型。

理解原理不是为了背概念，而是为了知道问题应该在模型、数据还是工作流里解决。
