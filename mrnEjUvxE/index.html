阿里云 ECS 修改主机名（hostname）

新买的阿里云 ECS，登录后 hostname 显示一串又长又随机的名字，看着难受。主机名改起来只要一行命令，但想“彻底生效”还涉及云控制台。这篇记一下完整步骤。

一、先看当前主机名

登录服务器后，先确认现在叫什么：

hostname

二、用 hostnamectl 永久修改

现代 Linux（CentOS 7+ / Ubuntu 16.04+）都用 hostnamectl，它同时改运行时状态和 /etc/hostname 文件，重启也保留：

hostnamectl set-hostname aliyun
名字怎么取：建议用小写字母、数字和连字符，别带下划线或特殊符号，避免某些服务解析时踩坑。这里随手改成 aliyun。

三、让修改真正生效

命令执行后，当前 shell 可能还显示旧名字。两种办法让它刷新：

  • 退出后重新 ssh 登录一次；
  • 或在阿里云控制台对实例做一次重启（注意是“重启”动作，不是停止再启动，部分场景需要重启才能让网络标识刷新）。

重新连接后，提示符前缀就变成了新主机名：

四、云控制台的“实例名称”也要改

注意 hostname 是系统内部的名字，阿里云控制台列表里显示的“实例名称 / 实例 ID”是另一回事。想让控制台也清爽，去 ECS 控制台 → 实例 → 更多 → 实例设置 → 修改实例名称 同步一下；否则系统里叫 aliyun、控制台里还是一长串，两头对不上。

顺带一提：如果只是临时看一眼，hostname 新名字 也能临时改（不写盘，重启还原），适合测试用，别和长期设置搞混。
