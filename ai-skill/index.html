AI Skill：把经验变成可复用的工作能力

Prompt 解决一次提问，Skill 解决一类重复工作。它是 AI 从“会回答”走向“会按方法做事”的关键一步。

Skill 和 Prompt 有什么区别

Prompt 往往是一段指令，告诉模型这一次应该怎么回答；Skill 则把目标、步骤、约束、参考资料和验收标准组织成一个可复用的能力。它更像一份给 AI 使用的操作手册。

一个完整 Skill 的组成

  1. 触发条件：什么时候应该使用这个能力，什么时候不应该使用。
  2. 执行流程：先收集什么信息，再调用哪些工具，最后如何交付。
  3. 参考资料：术语表、规范、示例和常见错误。
  4. 验收标准：结果必须包含什么，哪些情况需要暂停询问。
核心思路：不要把 Skill 写成“请认真完成任务”，要把隐含经验拆成模型可以检查的步骤。

以周报 Skill 为例

触发后先要求用户提供本周事项和目标，再把事项按成果、风险、下周计划分类；如果缺少数字就标记“待补充”，不能自行编造；输出前检查每项是否有明确动作和负责人。

Skill 如何和 MCP 配合

Skill 负责流程和判断，MCP 负责把外部工具接进来。比如“项目周报 Skill”可以规定先读取项目文档、再查询任务数据、最后生成摘要，而这些读取和查询动作由 MCP Server 提供。

如何让 Skill 越用越好

记录失败案例，补充边界条件；把优秀输出加入示例；为关键步骤增加人工确认。一个成熟的 Skill 不会越来越长，而会越来越明确。

Skill 沉淀的是方法，MCP 连接的是能力，两者组合起来，才像一个真正可以工作的 AI 助手。
